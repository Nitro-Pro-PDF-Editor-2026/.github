## Overview

Nitro Pro provides tools for creating, editing, reviewing, converting, and protecting PDF documents. Users can modify supported text and images, organize pages, add annotations, and prepare documents for sharing or archiving.

Its OCR capabilities recognize text in scanned documents and image-based PDFs, making supported files searchable and easier to edit. Additional features include document comparison, form handling, electronic signatures, and document optimization.

## Use Cases

Nitro Pro can support business correspondence, document review, form preparation, digital archiving, and routine PDF conversion. Annotation tools help reviewers mark important content, while editing and page management features simplify document preparation.

OCR is useful when working with scanned pages that do not contain selectable text. Recognition results depend on source quality, language settings, and document layout.
